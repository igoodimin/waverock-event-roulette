# 이벤트 추첨 돌림판

## 목표
- 인스타그램 아이디를 넣어 당첨자를 뽑는 돌림판.
- 인스타 업로드용 영상(4:5 피드 1080×1350, 9:16 스토리 1080×1920)을 MP4로 저장.
- 연출 핵심: 처음엔 아이디가 안 보일 만큼 빠르게 돌고, 느려지면 아이디가 보이며, 마지막에 아슬아슬하게 멈춰 긴장감을 준다.

## 범위
- `index.html` 파일 하나. 서버·빌드 없음. 최신 크롬 기준.
- 아이디는 직접 붙여 넣는다. 같은 아이디를 여러 번 넣으면 칸이 늘고 확률도 늘어난다(댓글 단 사람 2칸).
- 당첨자 수 조절, 제목·제목 색, 배경 사진(가우시안 블러), 소리.

## 비목표
- 인스타 댓글 자동 수집(정책상 불가).
- 로고 넣기(사용자 요청으로 제외).

## 제약·결정
- 배경색 #f5f5f5.
- 영상에 참가자 수·응모 수를 표시하지 않는다(사용자 요청).
- 아이디는 항상 `@`를 붙여 표시한다.
- 당첨은 crypto.getRandomValues로 뽑고, 매 회 칸 순서·시작 각도·회전 수를 무작위로 한다.
- 100칸 초과 시 칸에 글자를 쓰지 않고, 돌림판 아래에 바늘이 가리키는 아이디를 크게 보여 준다.
