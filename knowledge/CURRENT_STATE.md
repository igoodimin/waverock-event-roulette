## 실행·검증 방법
- 실행: `index.html`을 크롬으로 연다. 또는 폴더에서 `python3 -m http.server 8765` 후 http://localhost:8765
  - 8765 포트를 다른 파이썬 서버가 쓰고 있을 수 있음. 옛 화면이 보이면 8766 등 다른 포트로 띄운다.
- GitHub 올리기: `git push` (토큰은 Mac 키체인에 저장됨, 90일 만료 예정). 1~2분 뒤 Pages에 반영됨
- 사이트 카드·썸네일 수정: waverock-design-tools 저장소의 `tools.json`, `thumbs/event-roulette.jpg`(1280×800)
